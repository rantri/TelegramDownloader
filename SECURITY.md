# Reporting a security issue

Use GitHub's [private vulnerability report](https://github.com/rantri/TelegramDownloader/security/advisories/new) to contact the maintainer. Include the affected release, Windows version, the impact and the smallest synthetic example that demonstrates the behavior. The maintainer will follow up in that private advisory.

Keep Telegram API hashes, phone numbers, authentication codes, passwords, private post links, downloaded media and session files out of the report. If you suspect someone has your Telegram session, review active devices in Telegram under **Settings → Devices** and revoke the affected session.

Security fixes target the current stable release. Use [public issues](https://github.com/rantri/TelegramDownloader/issues) for ordinary bugs and feature requests.
