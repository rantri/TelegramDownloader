## First public Windows x64 release

Download `TelegramDownloader-2.0.0-win-x64.zip` and `SHA256SUMS.txt` from Assets. Follow the [PowerShell verification and installation steps](https://github.com/rantri/TelegramDownloader/blob/v2.0.0/README.md#get-the-windows-app). The executable includes the .NET runtime.

- Save the original video attached to a supported public or private Telegram post using your own account.
- Choose the desktop window to queue up to three parallel downloads, or run a single download from the command line.
- Completed files receive safe names. Failed or cancelled transfers preserve existing files.

**Upgrading from a local 1.x build** — Pass an existing destination folder to `download`. Version 2 selects the filename. Existing account configuration and sessions are compatible.

Run `TelegramDownloader.exe --version` to confirm the installation reports `2.0.0`.
